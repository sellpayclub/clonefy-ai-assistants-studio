🧪 Página de Teste - Widget Clonefy

Use esta página para testar os diferentes estilos do chat

📋 Como Testar:

  1. Abra o Console do Navegador (F12 ou Cmd+Option+I)
  2. Procure por mensagens que começam com CLONEFY: ou ===
  3. Verifique qual widget_template está sendo carregado
  4. Confirme se o estilo visual corresponde ao template configurado
  5. Se aparecer apenas o botão flutuante, mas o template configurado é outro, temos um problema!
⚠️ IMPORTANTE: Substitua SEU_ASSISTANT_ID_AQUI no código abaixo pelo ID real do seu assistente antes de usar este arquivo!

🔍 O que verificar no Console:

✅ CORRETO - Se você configurou "Card do Agente":
=== CLONEFY: TEMPLATE DETECTION ===
Widget Template: agent_card
Is Classic?: false
====================================

❌ INCORRETO - Se você configurou "Card do Agente" mas aparece:
=== CLONEFY: TEMPLATE DETECTION ===
Widget Template: classic
Is Classic?: true
====================================

Conteúdo da Página de Teste

Esta é uma página de teste simples para verificar se o widget está funcionando corretamente. O chat deve aparecer no canto inferior direito (ou esquerdo, dependendo da sua configuração).

Estilos Disponíveis:

  • Clássico: Apenas o botão flutuante no canto da tela
  • Balão de Mensagem: Botão + balão com mensagem de boas-vindas
  • Card do Agente: Card expandido com foto, nome, status e botões de ação
  • Perguntas Rápidas: Balões com perguntas pré-definidas clicáveis
